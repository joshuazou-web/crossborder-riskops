# 演示视频旁白稿(中文)

对应视频:[`docs/demo/demo-zh.mp4`](demo/demo-zh.mp4) · 字幕:[`docs/demo/demo-zh.srt`](demo/demo-zh.srt)

片中出现的每一笔交易、商户、钱包和风险标签都是**合成数据**,由固定随机种子生成,没有接触过真实支付网络或客户。旁白第二句就是这件事,不要在配音时略过。

视频是**无声**的,画面时长已经按下面每一段的朗读长度剪好。照着念一遍录成音轨,合到视频上即可,不需要再对轴。

字幕已经烧进画面下方的白色留白带里,不覆盖界面。如果上传到支持外挂字幕的平台,用 `.srt`,并把烧录版换成不加带的版本(改 `BAND_HEIGHT = 0`)。

全片 108 秒。语速按每秒约 4.5 个汉字设计,念得比这个快会对不上画面。

## 录音与合成

念的时候按段停顿,段与段之间留半秒,不必追求连贯——画面切分本来就在段边界上。

```bash
ffmpeg -i docs/demo/demo-zh.mp4 -i narration.m4a -c:v copy -c:a aac -shortest docs/demo/demo-zh-narrated.mp4
```

音轨比画面短会在结尾留静音,长了会被 `-shortest` 截断。差得多的话,先看是不是某一段念得太快,而不是去改视频。

## 重新生成画面

改了界面或想调节奏,重跑:

```bash
python -m streamlit run app/Home.py
python scripts/capture_demo_video.py
```

每段的时长写在 `scripts/capture_demo_video.py` 的 `BEATS` 里,和上面的段落一一对应。改了这里的字,就要改那里的秒数——脚本会检查每段画面是否够长,不够会直接报错而不是悄悄剪短。
